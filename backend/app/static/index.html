How to Connect
1
Pair HC-05 in Windows Bluetooth Settings.
Go to Settings → Bluetooth → Add device → select HC-05 → PIN: 1234.
After pairing it appears as a COM port (e.g. COM5).
2
Power ON your Arduino + MFRC522 circuit.
The HC-05 LED should blink rapidly — it's ready to pair.
3
Click "SCAN & CONNECT TO HC-05" above.
A native browser dialog opens — select your HC-05 COM port and click Connect.
4
Tap RFID tags!
Results appear instantly — no refresh needed.
Requires Google Chrome or Microsoft Edge. Web Serial API is not supported in Firefox or Safari.
